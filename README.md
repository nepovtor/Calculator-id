# IP Subnet Tools

This project now includes a subnet calculator and a training mode.

- **Calculator** – Enter an IP address in CIDR notation to see the subnet mask, network and broadcast addresses, and the available host range. Detailed steps for each calculation are presented one at a time with **Next** and **Previous** buttons.
- **Training** – Generates a random IP/CIDR and lets you practice by filling in the binary IP, subnet mask, network address, broadcast address, and host range. Your answers are checked instantly.

## Usage

Open `index.html` in a browser and choose **Calculator** or **Training** from the menu.
